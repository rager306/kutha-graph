<objective>
Add a bounded pack manifest and fail-closed operator declaration metadata.

Purpose: ADR-021 D021-1 names a pack as a versioned artifact with operators; C1 recorded lifecycle only. C1b adds the declaration surface without executing anything.

Output: manifest schema and parser, optional digest pin on PackInstall, admission validation, focused tests.
</objective>

## Tasks

1. Add `PackManifest` schema v1 (pack_id, name, version, operators) with canonical JSON bytes and `sha256_hex` address.
2. Add optional `manifest_digest` to `Op::PackInstall` with serde default so legacy events parse.
3. On `emit_pack_install`, allow a manifest: store the blob, then the install event pinning its digest.
4. In admission, require the cited blob to exist, parse as schema v1, match pack identity, and declare unique non-empty non-reserved operator names that do not collide with another installed pack.
5. Add tests for valid install, missing blob, malformed/mismatched manifest, reserved/duplicate/cross-pack collision, and legacy manifest-less install.
6. Document the PackInstall wire change and non-goals.
