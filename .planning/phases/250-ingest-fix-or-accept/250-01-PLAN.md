<objective>
Remove the named ingest cost, or record why it is the accepted tradeoff.

Purpose: the bisect names a cause; this phase decides whether the cost can be removed without changing log semantics.

Output: a scoped product change with tests and bench, or an explicit tradeoff.
</objective>

## Tasks

1. Read the first-bad commit and its parent diff; identify the ingest path.
2. Apply the smallest fix; do not change Op wire, event order, or fold semantics.
3. Run `cargo test --workspace` and `uv run kutha-gov ci --jobs 1`.
4. Run interleaved old/HEAD/post-change at N=10000; record `ingest_plain.n` samples and median.
5. If the cost is accepted, record the cause and the range; do not claim a win.
6. CHANGELOG Product/Process and benchmark baseline update.

## Gates

```text
cargo test --workspace
uv run kutha-gov ci --jobs 1
KUTHA_BENCH_N=10000 cargo bench -p kutha-runtime --bench baseline
```

## Stop

The fix changes semantics or the bench does not separate the change from noise; record the tradeoff instead.
