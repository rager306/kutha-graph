## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Disk dir → store::open | Untrusted JSONL lines; corrupt outcomes must fail parse, never invent Full |
| Runtime::emit → outcomes buffer | Call Ok is not completion; disposition must reflect abort×count |
| Crash / missing sidecar → disposition query | Events on disk without Full must not read as terminal success |
| Caller → record_resume | Resume identity must be explicit; open must not auto-call |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-01 | Spoofing | store::open disposition query | high | mitigate | Never synthesize Full from events alone; missing outcomes file ⇒ empty list (OUT-01/02, D-O3) |
| T-05-02 | Tampering | quantum_outcomes.jsonl parse | high | mitigate | Typed serde_json line parse; InvalidData on corrupt lines like events.jsonl |

| T-05-04 | Replay | Runtime::record_resume | medium | mitigate | Thin fail-closed if resume_of already present (D-O4); open does not auto-resume (D-O3) |
| T-05-05 | Tampering | Snapshot early-return path | high | mitigate | Load outcomes on every open return path including snapshot (D-O1 / ADR-010) |
