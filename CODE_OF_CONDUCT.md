# Code of conduct

Discussion on this repository stays specific and evidence-based. Disagree with the claim, not the person. Harassment, slurs, and doxxing are not acceptable.

Report conduct problems the same way as a vulnerability: [GitHub private vulnerability reporting](https://github.com/rager306/kutha-graph/security/advisories/new). There is no separate conduct committee. The maintainer reads the report and decides what to do, including closing a thread or blocking an account.

This file is the repository conduct policy. It is not the Contributor Covenant and it does not add a license.
