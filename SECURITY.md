# Security

Kutha is a **research-stage** engine. It is not a supported product, and `0.0.0` is not a release. The only code in scope for a report is the default branch of this repository.

## Reporting

Report a vulnerability through [GitHub private vulnerability reporting](https://github.com/rager306/kutha-graph/security/advisories/new). Do not open a public issue for a security report.

Include what you ran, what you expected, and a minimal input if you have one. There is no bug-bounty program and no response-time promise.

## Out of scope

- Honeycomb ADR text (`docs/ADR/`) that is still **Proposed** and not in the running engine.
- Other repositories, containers, or corpora on a developer machine.
- A question about the Apache-2.0 license. That is not a vulnerability.
