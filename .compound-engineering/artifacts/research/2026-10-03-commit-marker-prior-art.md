# COMMIT-01 prior art: atomic multi-record commit markers

**Date:** 2026-10-03. **Scope:** how other logs mark a multi-record group committed so crash recovery hides an uncommitted prefix. **Kutha local (source, CBM stale on `wal.rs`/`persist_append.rs`):** `events.jsonl` is SoT (one `Event`/line); `events.wal` is lease (`KUTHAWAL` v1, len+crc32+JSON, one frame/event). `Persister::append` writes the encoded suffix then **one** WAL `sync_data`. `recover_events` drops a torn/CRC-fail **last frame** (`kTolerateCorruptedTail` analog) but **keeps** CRC-valid payload frames that lack a trailing `Op::QuantumOutcome`. User `emit` always appends QO last (`persist_outcome_event`); Dictionary/Typed paths do not. ADR-010/014 leave COMMIT-01 open (F11: QO vs commit frame). ADR-012: snapshot `tt_anchors` vs log `TtAnchor`.

**Verify tags:** `(page)` = claim read from that URL’s body; `(snippet)` = search/engine excerpt only.

## 1. Systems

| System | How a multi-record group commits | Recovery of uncommitted / torn tail |
|--------|----------------------------------|-------------------------------------|
| **SQLite WAL** | Last frame of a tx is a **commit frame**: frame hdr bytes 4–7 = post-commit DB size in pages; non-commit frames store 0. ([fileformat](https://www.sqlite.org/fileformat.html) `(page)`; [walformat](https://www.sqlite.org/walformat.html) `(page)`) | Scan WAL; stop at first bad checksum; `mxFrame` = last **valid commit** frame. Frames after that commit are discarded. `(page)` |
| **Postgres** | Changes + a later **commit** are WAL records; on commit the xid is marked in `pg_xact`. ([wal-intro](https://www.postgresql.org/docs/current/wal-intro.html) `(page)`; [transaction-id](https://www.postgresql.org/docs/current/transaction-id.html) `(page)`) | REDO from checkpoint. Uncommitted xids are not marked committed → MVCC-invisible. StackExchange: replayed but invisible without COMMIT `(snippet)` [dba](https://dba.stackexchange.com/questions/301428/what-happens-to-written-wal-logs-if-a-transaction-is-aborted-in-the-middle). |
| **RocksDB** | `WriteBatch` is one WAL unit (seq+count+ops). 2PC adds Prepare(xid)/EndPrepare/Commit(xid)/Rollback(xid) inside batches. ([2PC wiki](https://github.com/facebook/rocksdb/wiki/Two-Phase-Commit-Implementation) `(page)`) | Modes ([wiki](https://github.com/facebook/rocksdb/wiki/WAL-Recovery-Modes) `(page)`): **kTolerateCorruptedTail** ignore tail IO; **kAbsoluteConsistency** any WAL IO = corruption; **kPointInTime** stop at first error (default ≥6.6); **kSkipAnyCorruptedRecords** salvage. 2PC: reconstruct prepared; commit/rollback markers decide memtable insert. Old binary fatals on unknown record ids `(page)`. |
| **Kafka** | Records live in the log immediately; **COMMIT/ABORT control records** (KIP-98 types 0/1) plus `__transaction_state`. ([KIP-98](https://cwiki.apache.org/confluence/display/KAFKA/KIP-98+-+Exactly+Once+Delivery+and+Transactional+Messaging) `(page)`) | `read_committed` does not fetch past **LSO** (first offset of any open txn); aborted batches skipped via marker metadata. Timeout aborts. Records are **not** deleted. ([Confluent](https://developer.confluent.io/courses/architecture/transactions/) `(page)`) |
| **FoundationDB** | Commit proxy batches mutations, assigns one version, **durably writes the batch to tLogs** (disk-queue); client sees commit only after that. ([dev guide](https://apple.github.io/foundationdb/developer-guide.html) `(page)`; [tlog-spilling](https://github.com/apple/foundationdb/blob/main/design/tlog-spilling.md.html) `(page)`) | In-flight client mutations never on tLogs are gone. tLog crash rebuilds in-memory queues from the disk queue of **committed** batches. Recovery version = last durable commit. |
| **Datomic** | Tx is an **unordered set of datoms at one t**; transactor **reifies a tx entity** (`:db/txInstant`). Every datom carries `tx`. ([glossary](https://docs.datomic.com/glossary.html) `(page)`; [tx-data](https://docs.datomic.com/transactions/transaction-data-reference.html) `(page)`) | No prefix of a tx is a database value. Log is an accumulate-only tree of whole transactions ([log API](https://docs.datomic.com/reference/log.html) `(page)`). Closest cousin of Kutha QO-as-entity. |
| **EventStoreDB / Kurrent** | `AppendToStream` is atomic for the list. TF: `PrepareLogRecord` flags `TransactionBegin/End`; `IsCommitted` means no later commit; else `CommitLogRecord(transactionPosition, firstEventNumber)`. SingleWrite = Data\|Begin\|End. ([Prepare](https://github.com/kurrent-io/KurrentDB/blob/master/src/KurrentDB.Core/TransactionLog/LogRecords/PrepareLogRecord.cs) `(page)`; [Commit](https://github.com/kurrent-io/KurrentDB/blob/master/src/KurrentDB.Core/TransactionLog/LogRecords/CommitLogRecord.cs) `(page)`; [append](https://docs.kurrent.io/clients/tcp/dotnet/21.2/appending) `(page)`) | Index/read only committed prepares (IsCommitted or matching Commit). Uncommitted prepare tail is not in the stream. gRPC `appendRecords`/`multiStreamAppend` (25.1/26.1) are all-or-nothing. |
| **TigerBeetle** (2023–) | Prepare written to replica WAL; commit after replication quorum; WAL is SoT, replayed from checkpoint. ([safety](https://docs.tigerbeetle.com/concepts/safety) `(page)`; [vsr.md](https://github.com/tigerbeetle/tigerbeetle/blob/main/docs/internals/vsr.md) `(page)`) | View-change **truncates uncommitted ops**; PAR repairs corrupt prepares from other replicas; nack/CTRL. Incomplete local prepare ≠ committed. |
| **Turso / Limbo** (2024–) | SQLite **file-format compatible** (dialect, files, C API; not 100% yet). ([README](https://github.com/tursodatabase/turso) `(page)`) | Same physics as SQLite WAL: last commit frame + checksum stop. Extra: `.tshm` multi-process WAL. |
| **Fjall** (2024–26) | Journal batch = **Start + items + End**; cross-keyspace atomic in one journal. ([issue #308](https://github.com/fjall-rs/fjall/issues/308) `(page)`; README durability `(page)`) | `JournalBatchReader` truncates to `last_valid_pos` before an unterminated Start. Mid-journal Start-without-End looks like corruption and can drop **later** good batches (#308); #311 asks Strict vs torn-tail (Rocks PIT vs tolerate-tail). |
| **redb** | CoW B+tree; default **1PC+C**: write data+checksums+tx id, flip primary, one `fsync`. Optional 2PC (fsync, then flip, fsync). ([design.md](https://github.com/cberner/redb/blob/master/docs/design.md) `(page)`) | Crash: if primary tx id/checksums fail, **roll back to secondary**. No log prefix: commit is atomic root swap. |
| **SlateDB** | `WriteBatch` one seqnum; `WalWriter::append` must be **all-or-none** for that seq. Durability = object-store flush (`await_durable`). ([WalWriter](https://docs.rs/slatedb/latest/slatedb/wal/trait.WalWriter.html) `(page)`; [writes](https://slatedb.io/docs/design/writes/) `(page)`) | Iterator sees all rows of a seqnum or none. Process death **before** remote flush **loses** in-memory WAL ([FAQ](https://slatedb.io/docs/get-started/faq/) `(page)`). |
| **Neon** | Postgres WAL streamed; commit when **quorum of safekeepers** ack the **commit-record LSN** (Paxos). ([architecture](https://neon.tech/docs/introduction/architecture-overview) `(page)`; [protocol](https://github.com/neondatabase/neon/blob/main/docs/safekeeper-protocol.md) `(page)`) | Proposer recovers max(flushLSN) from quorum and treats it committed to avoid losing committed data. Uncommitted = not quorum-acked. Pageserver replays **committed** WAL. |

Theory: ARIES commit records + redo/undo ([ARIES](https://consensus.app/papers/details/f588de829671501ea8b9b6878d1c58af/?utm_source=cursor)); FineLine single log-structured store ([FineLine](https://consensus.app/papers/details/c9102e6c69ca51049de5cdfdb579e79e/?utm_source=cursor)); PALF replicated WAL (VLDB 2024) ([PALF](https://consensus.app/papers/details/b13827968d3d5397a991fb687f7abfca/?utm_source=cursor)); CPR group-commit prefix ([CPR](https://consensus.app/papers/details/7a0f38e202cf582a9c607997e68d4935/?utm_source=cursor)).

## 2. Trade-offs for Kutha

| Axis | A: QO event as marker | B: WAL commit flag/frame | C: one envelope frame (N events, one CRC) | Extra frame besides QO |
|------|----------------------|--------------------------|-------------------------------------------|-------------------------|
| **Format cost** | Writer unchanged; recovery policy only. | WAL v2 header bits or extra record; jsonl SoT still needs a semantic ender or WAL-led truncate. | Breaks one-event-per-frame and likely one-event-per-line. | QO is already +1 event in the **same** `sync_data`. A second commit frame is pure overhead unless QO is removed (conflicts with ADR-014 log-native outcomes). |
| **Torn-tail** | Must **trim** after D-04 to last sealed User quantum; per-frame CRC is not enough (today’s gap). | SQLite-like: last commit-flagged frame is the durable end; O(scan-back) or store offset in snapshot. | Atomic iff the whole quantum is one CRC; torn envelope = drop all N. | Flag on the **QO frame** = B piggyback, zero extra records. |
| **jsonl SoT / replay** | Lines stay `Event` JSON. Old `jq`/replay still parse. Trim is a **policy**, not a schema break. | WAL-only flag does **not** hide jsonl prefix from a jsonl-only replayer. | One JSON array/line breaks “one event per line” and old `Event` parse. | — |
| **Tail-guard O(1)** | Unchanged: last line id vs last frame of `last_frame_len`. | Keep if commit is a **flag on the last existing frame**. Extra empty commit frame needs guard to skip it. | `last_event_id_at_end` must learn envelopes. | — |
| **Segment sealing (S06)** | QO is a logical seal; no byte-size in the frame. | SQLite `db-size` analog = jsonl/WAL byte offset on the commit frame — best later seal. | Envelope size is the seal; large quanta = huge frames. | — |
| **TT** | QO consumes `next_tt`; payload TTs already assigned. Trim before fold/`replay_check` keeps committed TT map. | Flag does not allocate TT. | Bundling N events into one log record collides with per-event TT. | Do not replace QO solely to save one TT. |

Dictionary/Typed/Define suffixes have **no** QO by design (log-growth oracles). Naive “drop after last QO” is wrong; prior art analog is EventStore `IsCommitted` on single writes vs explicit Commit on multi-prepare.

## 3. Compat matrix

| Design | Old jsonl `Event` parser | Old WAL v1 reader | Write-time selectable / reader accepts both |
|--------|--------------------------|-------------------|---------------------------------------------|
| **A** recovery trim | **Yes** (same bytes). Semantics: old open **without** trim still **sees** payload-without-QO. | **Yes** (v1 frames). | Policy on `open`, not a write mode. |
| **B** WAL v2 flag | Yes if jsonl unchanged. | **No** (`unsupported WAL version` → existing jsonl fallback). Fallback **re-exposes** jsonl prefix unless A-trim also runs. | **Yes**: writer v1 or v2; reader v1+v2. Rocks 2PC wiki: unversioned WAL, old code **fatals** on new markers `(page)` — Kutha should **version**. |
| **C** envelope | **No** if a line is not one `Event`. | **No** (JSON/CRC stop → drop envelope). | Dual-read possible; old writer cannot produce envelopes. |
| **D** hybrid | Depends on modes. | Dual-read. | Yes, but crash-matrix × modes; Kafka-like `isolation.level` is a **read** switch, not a write-format switch. |

**Old replayer still reads the log:** A (format). B/C only if they keep one `Event` per jsonl line and v1 WAL frames. **Write-time select + dual-read:** B-with-v2-flag on existing frames, or D; not C unless envelope is WAL-only and jsonl stays N lines (then jsonl is still non-atomic).

## 4. Ranked recommendation

1. **A (keep `Op::QuantumOutcome`; trim typed uncommitted suffix on `open` before hydrate/`replay_check`).** Matches Datomic tx-entity, EventStore commit/IsCommitted, Kafka markers, Postgres commit xid: **the SoT log carries the seal**. jsonl stays human-readable. No WAL version bump. QO already paid the extra-record cost. Physical cousins (SQLite commit bit, Fjall Start/End, Rocks 2PC) belong on the **WAL lease** later, piggybacked on the QO frame when S06 seals segments — not as a replacement for log-native outcomes (ADR-014).
2. **B piggyback (v2 flag on last frame of a synced batch)** — only with dual-read + A-trim so jsonl fallback cannot resurrect a prefix. Defer to S06.
3. **C** — reject for SoT jsonl; maybe later WAL-only for huge quanta.
4. **D write-time env dual-encoding** — reject for S05 (combinatorial oracles, no extra durability vs A+optional later B).

**Flip A:** (i) crash oracle `payload-without-QO` still **folds** after A-trim (then A is wrong or typed classifier is); (ii) measured open-trim cost or QO byte bloat dominates ingest (F11 3×) **and** receipts can move off the log — then B/C; (iii) S06 needs O(1) seal-by-bytes — add SQLite-style size on the QO frame without dropping QO; (iv) Jepsen/failpoint: kill after N−1 frames of Assert+QO, `open` must not expose Assert, intern-only Define suffix must survive.
