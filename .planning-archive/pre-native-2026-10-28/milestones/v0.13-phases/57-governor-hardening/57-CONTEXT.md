## Locked decisions

- **D-01 (intake):** follow `docs/process/governor-intake.md` and `.kutha/META.md`: a check is a YAML row; one new *kind* is allowed because no existing kind parses TOML (record this in the intake table, `disposition: kind`). No new Check subclass, no `scripts/kutha_gov/checks/*.py`.
- **D-02 (GOV-04, RED first):** new kind `cargo_dep_constraint` in `scripts/kutha_gov/kinds.py`, stdlib `tomllib` only. Inputs: globs of Cargo.toml files; rules per dependency name: `forbid`, or `require_optional`. It walks `[dependencies]`, `[dev-dependencies]`, `[build-dependencies]`, `[target.*.dependencies]`, `[workspace.dependencies]`, and both inline and table forms (`[dependencies.NAME]`). `freeze-rocks` = `require_optional` for `rocksdb` in `crates/*/Cargo.toml`, `forbid` in the root `Cargo.toml`; `freeze-cypher-deps` = `forbid` for the Cypher/graph-DB crate names currently needle-matched (keep the same name list, match as dependency keys not substrings); `freeze-hnsw-dep` = `forbid` for `hnswlib`/the current HNSW names. Comments never trigger; a missing or unparsable TOML is a HIGH finding (fail closed), a missing glob match is not. Pytest first (`FreezeDepTests`): every bypass form from the audit is RED on the old rule and GREEN on the new one: `[dependencies.rocksdb]` plain, `rocksdb="0.22"`, `rocksdb = "0.22" # optional = true`, a second `optional = true` on the same line for another key, `[workspace.dependencies.rocksdb]`, `[target.'cfg(unix)'.dependencies] rocksdb`, `package = "rocksdb"` rename (`foo = { package = "rocksdb" }`). Comment-only mention passes. The real tree passes (optional rocksdb in kutha-runtime). The Phase 51 `unless_file_contains` / `unless_line_contains` kind fields may be deleted with their tests only if nothing else uses them (rg first); otherwise leave.
- **D-03 (GOV-05, enrol M002 oracles):** (a) add the existing `m002_*` test fn names (chosen from `crates/kutha-runtime/tests/m002_*.rs`; at least the headline oracle per phase 50–55: SNAP-01, APPEND-01, COMMIT-01, SEG-01, ROCK-00, ROCK-01) to `fsm.yaml` `observe_cargo.required` — default `cargo test --workspace` runs all except `#![cfg(feature = ...)]` files; (b) add a second observe row (or `args`) that runs `cargo test -p kutha-runtime --features rocks-index --test m002_rock01 --offline` for ROCK-01 and the spike feature for ROCK-00; if the cold RocksDB build time makes a row unacceptable for `ci` (>6 min cold), mark that row `optional: true`/non-default with an explicit reason in the YAML and a note in `docs/process/governor-intake.md`, and keep it in the controller bench/verification step instead; measure and record the warm and cold times. (c) honeycomb.yaml ADR-010/012 evidence from Phase 56 already lists names; the ledger check must resolve them (`rust_test_asserts`). Do not enable features by default in Cargo.toml.
- **D-04 (GOV-05, budget and id map):** `artifact-budget`: `min_hits: 1` while a live `.planning/phases/*` directory with a CONTEXT exists, `allow_empty` only when no live phase directory exists (implement through existing kind options or a `when_glob_exists` condition if one exists; otherwise a tiny option on the existing kind, with a test); SUMMARY `max_files_per_dir: 1`. Selftest for that check must not skip when a live phase exists (make the skip data-dependent, not unconditional). `id-map-cite` requires `v0.12` and `v0.13` rows in `gsd-auto-contract.md` (keep `v0.06`–`v0.09`).
- **D-05 (GOV-06, selftest honesty):** for the kinds the audit lists as not derivable (`yaml_map_list`, `pointer_in_other_file`, `git_path_implies`, `markdown_heading_tag`, `glob_none`, `glob_paths_in_file`, `when_match_then_match`) either add a derivable mutation (mutate the ledger/pointer so the *check's own rule* fails, not `file_exists` deletion) or give the check an explicit `selftest: skip` with a one-line reason. Add a selftest guard test: every check is classified `derived-by-own-mutation`, `explicit-mutation`, or `explicit-skip(reason)`; a check proven only through `file_exists` deletion is reported (LOW finding) so nobody mistakes it for proof. Do not weaken or remove any existing check.
- **D-06 (non-goals):** no parallelism (S03), no ci time cuts (S03), no theatre-check deletions (S03/S04 decide), no change to check ids or severities beyond D-04, no crate edits, no ADR text. Duplicate `i-f*`/`m012a-*` rows are not merged here.
